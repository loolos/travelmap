## 3. 里程碑細節

### M0 基礎框架（11/23–11/24）

1. Vite＋React＋TypeScript 專案、CSS Modules、ESLint、Vitest。
2. 埃及簡化地圖（Natural Earth 國界＋尼羅河），d3-geo 投影，節點元件，拖曳與縮放。
3. HashRouter：`/#/map`、`/#/place/:id`、`/#/place/:id/:activity`、`/#/offline`、`/#/journal`。
4. 內容 schema（Zod）與校驗腳本；以 2 個範例地點（胡夫金字塔、白沙漠）跑通。
5. 地點頁輕模板：桌面右側面板、手機底部抽屜。
6. Service Worker（injectManifest）、離線清單產生、離線下載頁（進度、重試、就緒檢查）。
7. IndexedDB 進度儲存。
8. GitHub Actions 部署至 Pages；在真實 `/travelmap/` 子路徑驗證斷網重開。

**完成條件**：在 Pages 上，Chromium 自動化測試能下載核心包、斷網、重開並看到地圖與 2 個地點。

## 6. iPhone 離線測試清單（D-3，11/30）

在 iPhone 上照順序做，任何一步失敗就回報截圖：

1. 用 Safari 開 `https://loolos.github.io/travelmap/`。
2. 分享 → **加入主畫面**。（重要：iOS 會清除超過 7 天沒開的網站資料，加入主畫面的 App 不受此限。）
3. 從主畫面圖示開啟，進「離線下載」，按「下載全部核心內容」，等到顯示「離線就緒」。
4. 完全關掉 App（上滑關閉）。
5. 開啟**飛行模式**（同時關 Wi‑Fi）。
6. 從主畫面圖示重新開啟，檢查：
   - 地圖出現，可縮放、拖曳。
   - 隨機開 5 個地點頁，主圖都有顯示。
   - 5 個旗艦互動都能操作。
   - 標記一個地點「已到訪」，關掉 App 再開，狀態還在。
7. 關閉飛行模式，確認一切正常。

12/2 再連 Wi‑Fi 開一次，確認拿到最終版且仍顯示「離線就緒」。

## 7. 品質與測試

- 內容校驗（CI）：ID 唯一、引用完整、必要圖片存在、來源不為空、文字長度警告、簡體字偵測。
- 單元測試：金字塔產能模型、水庫模型、船閘狀態機、進度儲存。
- Playwright（Chromium）：首次下載 → 斷網 → 重開 → 抽查地點與互動；下載中斷後補齊；刪除單一快取後顯示未就緒。
- 體積報告：每次建置輸出 Core 大小。
- 每個 PR 附：完成項目、測試結果、未完成項目、資源體積、已知限制。

## 9. 風險

| 風險 | 影響 | 對策 |
|---|---|---|
| iOS 清除網站快取 | 旅途中無法離線 | 加入主畫面；D-3 實測；12/2 再開一次 |
| 時間不夠 | 部分旗艦未完成 | 第 3 節的取捨順序；輕模板優先覆蓋全部地點 |
| 圖片授權或品質不足 | 主圖缺失 | Wikimedia 為主；找不到合適照片時用 AI 示意圖並標示 |
| 內容事實錯誤 | 誤導 | 每則事實附來源；不確定的標「待審核」不上線 |
| 行程臨時調整 | 地點不符 | 地點不分日，隨時可點，不受順序影響 |
| 核心包過大 | 下載慢、iOS 空間不足 | 主圖壓縮至約 200 KB；非必要圖片連結線上 |
